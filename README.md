# Iron Cell Arena V2

브라우저 기반 탱크 성장 게임입니다.

## V5.82 시각 개선

- 진화체 포신이 차체에 가려지지 않도록 길이와 탄환 발사 위치를 함께 조정했습니다.
- 기존 30종 탄환 외형을 유지하고, 신규 16종에는 각각 전용 탄환 실루엣을 더했습니다.
- 46종 대포 모두 탄환에 종별 고유 발사 표식을 더했습니다.
- 평타 포구와 스킬 시전 이펙트에 대포별 색과 형태를 연결했습니다.
- `node --check game.js`와 `node visual-regression.cjs`로 기본 검사를 실행할 수 있습니다.

## V5.83 스킬 범위 및 중앙 무리

- 모든 46종 탱크의 Q 스킬과 R 스킬 보유 탱크의 범위 미리보기를 채웠습니다.
- 박격포는 5개 폭격 지점을, Oracle은 자동 표적을 조준 중 표시합니다.
- 월드 중앙에 오각형 200마리를 밀집 배치하고 처치된 자리를 다시 채웁니다.
- 중앙 무리는 일반 도형 수 제한과 분리되며 온라인 월드 스냅샷에 동기화됩니다.

## V5.84 트윈 대포 외형

- 트윈 진화 후 두 포신의 교대 발사를 유지하면서 장착한 대포의 고유 외형을 양쪽에 그대로 표시합니다.

## V5.85 능력치 버튼 및 쿼드 탱크

- 능력치 갱신 중에도 `+` 버튼을 교체하지 않고 클릭 영역을 키워 입력 누락을 줄였습니다.
- 쿼드 탱크의 기본 공격 피해 감소를 제거했습니다.

## 계정
- Supabase Auth 사용
- Pigeon Defense와 같은 Supabase Auth 계정 체계를 사용합니다.
- 기존 Pigeon Defense 아이디/비밀번호로 로그인할 수 있습니다.
- 자동 로그인

## Codespaces 실행
터미널에서:

```bash
python3 -m http.server 8000
```

그 다음 Codespaces가 표시하는 **Open in Browser**를 누르세요.

정적 사이트이므로 빌드 과정은 필요 없습니다.

## V5.86 스킬 처치와 범위 미리보기
- 지속 스킬로 HP가 0이 된 도형도 즉시 처치됩니다.
- Oracle 탐색 범위는 테두리로 표시해 화면을 초록색으로 덮지 않습니다.

## V5.87 탄환 및 스킬 연출
- 모든 탄환에 대포 테마색 광선과 보조 궤적을 더하고 고유 탄환 실루엣을 유지했습니다.
- 활성 범위 스킬에 회전하는 이중 원, 눈금, 육각 문양의 마법진을 추가했습니다. 연막과 직선 장벽은 원래 형태를 유지합니다.
- 고밀도 전투에서는 장식 단계를 줄여 그리기 비용을 제한합니다.

## V5.88 마법진 세부 표현
- 참고 이미지의 동심원, 겹친 별, 테두리 눈금과 작은 룬 문양을 범위 스킬에 반영했습니다.
- 탱크 계열 색을 유지하고 전투 밀도가 높을 때 작은 문양을 생략합니다.

## V5.89 탄환 외형과 이펙트
- 기존 46종 고유 탄환 실루엣 주위에 대포별 테마색 에너지 날개, 고리, 궤적, 작은 불꽃을 추가했습니다.
- 탄환 앞부분의 반짝임을 더하고, 화면이 복잡할 때 추가 장식을 생략합니다.

## V5.90 트윈과 Singularity
- 트윈이 두 포신에서 같은 발사 주기에 동시에 탄환을 발사합니다.
- 최고 레벨 45 달성 시 고죠 Singularity 대포가 영구 해금됩니다. 뽑기에는 포함되지 않습니다.
- 고죠 Q 아오는 인력장, E 아카는 척력 폭발, 두 버튼을 함께 누르면 두 쿨다운을 사용해 무라사키 광선을 발동합니다.
- 서버의 해금 함수가 저장된 최고 레벨 45를 검사합니다.

## V5.91 고죠 해금 표시와 공격 연출

- 최고 레벨 45 미만의 차고에는 고죠 카드를 표시하지 않습니다. 서버도 장착 시 최고 레벨 45를 다시 검사합니다.
- 고죠 평타는 푸른색과 붉은색 에너지가 교차하는 전용 포구 연출과 회전하는 탄환으로 표시합니다.
- 아오와 아카의 회전 에너지 흐름, 무라사키의 색상 교차와 끝부분 폭발을 강화했습니다.

## V5.92 고죠 스킬 연출

- 아카는 E를 누르는 동안 대포 앞에 붉은 구슬이 맺히고, 놓으면 빠르게 날아가는 연출로 바뀝니다.
- 아오는 커서 위치의 큰 푸른 원에 회전하는 바람을 표시하며, 시전 후 주변 도형을 중심으로 끌어옵니다.
- 무라사키는 푸른색과 붉은색 에너지가 교차하는 독자적인 광선 연출을 사용합니다.

## V5.94 고죠 연출 재구성

- 고죠 스킬에서 공통 마법진을 제거하고 각각 다른 응축·발사·흡인 움직임으로 교체했습니다.
- 아오는 커서 위치의 푸른 핵으로 공기 흐름과 입자가 나선형으로 빨려 들어가며 적을 끌어옵니다.
- 아카는 대포 앞에서 붉은 에너지가 응축된 뒤 버튼을 놓는 순간 고속 구체로 발사됩니다.
- 무라사키는 고정 광선 대신 작은 보라색 핵이 전진하며 뒤쪽 공간과 색을 길게 끌고 가는 연출입니다.

## V5.95 고죠 조작·충돌 판정 재구성

- 아오는 Q를 누르는 동안만 활성화됩니다. 푸른 핵이 실시간으로 커서를 따라가며 범위 안의 적을 계속 끌어당기고 지속 피해를 줍니다.
- 아카는 응축된 붉은 탄체가 목표 지점에 도착한 뒤 폭발하며, 비행 중 목표 지점에 미리 피해나 밀치기가 적용되지 않습니다.
- 무라사키는 아오와 아카가 양쪽에서 휘어 들어와 합쳐지는 준비 동작 뒤 보라색 탄체가 전진합니다.
- 무라사키 피해는 발사 순간의 직선 전체에 즉시 적용되지 않고, 이동하는 탄체의 충돌 범위가 적에게 닿을 때만 적용됩니다.

## V5.96 고죠 지급 복구

- 관리자 패널은 검증 가능한 `iron_cell_admin_set_cannon_v2`를 우선 호출하고, 지급 후 서버 프로필을 다시 조회해 실제 저장 여부를 확인합니다.
- 고죠 장착 플레이어가 죽으면 정산 완료 후 피해를 준 플레이어와 실행 ID를 서버에 증명합니다.
- 처치자는 동일 실행 ID를 재확인하며, 양쪽 증명이 일치한 경우에만 고죠가 소유 대포에 추가됩니다.
- 피해자의 정산보다 처치 알림이 먼저 도착하는 경우를 위해 처치 확인을 제한적으로 재시도합니다.
