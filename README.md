# Iron Cell Arena V2

브라우저 기반 탱크 성장 게임입니다.

## 계정
- Supabase Auth 사용
- Pigeon Defense와 같은 Supabase Auth 계정 체계를 사용합니다.
- 기존 Pigeon Defense 아이디/비밀번호로 로그인할 수 있습니다.
- 자동 로그인
- 로그아웃
- PC/모바일 같은 계정 기록 공유
- 저장: 파일럿 이름, 최고 레벨, 최고 점수, 최고 처치, 총 출격 수, 총 처치 수

## Codespaces 실행
터미널에서:

```bash
python3 -m http.server 8000
```

그 다음 Codespaces가 표시하는 **Open in Browser**를 누르세요.

정적 사이트이므로 빌드 과정은 필요 없습니다.
